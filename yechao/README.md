# 夜潮 NOCTIDE v3.1.0

纯静态前端影视目录与播放器。此版本新增苹果 CMS V10 资源站管理，浏览器直接请求 Provide/Vod 采集接口，不再依赖 Nginx 或固定反向代理路径。

## 部署

将本目录内文件上传到任意静态站点目录即可。项目已使用相对资源路径，可部署在 GitHub Pages 子目录（例如 `/yechao/`）。无需构建、数据库、Worker 或服务器端代码。

运行时文件：

- `index.html`：页面入口
- `app.js`：首页、搜索、分类、收藏、历史与播放器逻辑
- `source-manager.js`：资源站管理、订阅和检测
- `style.css`：页面样式
- `hls.min.js`：本地 HLS 播放库，不依赖第三方 CDN
- `sources.json`：首次启动时导入的默认线路清单
- `favicon.svg`、`version.json`：图标与版本信息

## 资源站管理

页面右上角打开「资源站管理」：

1. **手动添加**：填写线路名称和苹果 CMS V10 API 地址，例如 `https://example.com/api.php/provide/vod/`。
2. **线路检测**：请求 `?ac=list`，检查 HTTP 状态、JSON 格式及分类/列表字段；显示响应耗时。
3. **线路选择**：启用/禁用线路，并设置默认使用线路。主线路请求失败时会按启用顺序尝试其他线路。
4. **订阅管理**：添加返回 JSON 数组的订阅 URL，支持 `[{"name":"线路名","api":"https://.../api.php/provide/vod/"}]`，或 `{ "sources": [...] }` / `{ "list": [...] }` 格式。订阅更新会按线路 ID 合并；没有 ID 时按 API 地址生成稳定 ID。
5. **配置备份**：支持 JSON 导入、导出。

线路、订阅、收藏、历史均保存在当前浏览器的 `localStorage`，不同浏览器/设备不会自动同步。

## 重要：跨域限制（CORS）

本版本按要求取消反向代理，前端直接从浏览器访问资源站。**资源站必须允许你的网站来源跨域访问（CORS）**，否则浏览器会阻止读取 API 响应，表现为“跨域或网络失败”。这不是前端代码可以绕过的限制。`no-cors` 也无法读取 JSON，不能作为解决方案。

检测结果：

- `正常`：接口可跨域访问，且返回苹果 CMS 风格 JSON。
- `跨域或网络失败`：常见原因是源站未开放 CORS、DNS/证书或网络不可达。
- `请求超时`：10 秒内没有完成响应。
- `接口异常`：HTTP 错误或响应结构不符合预期。

注意：部分默认清单里的旧接口可能是其他 JSON API，不一定兼容苹果 CMS V10；可以在管理面板中禁用或删除。建议以检测结果为准。

## 苹果 CMS V10 请求参数

本前端主要使用：

- 分类：`?ac=list`
- 视频列表：`?ac=videolist&pg=1&pagesize=24`
- 搜索：`?ac=videolist&wd=关键词`
- 详情：`?ac=detail&ids=视频ID`

## GitHub Pages 子目录部署

将文件放在仓库的 `yechao/` 目录后，确保 Actions 的发布步骤会包含该目录。页面引用均使用 `./` 相对路径，不会错误请求域名根目录下的 `/app.js` 等文件。无需修改现有 Actions。
