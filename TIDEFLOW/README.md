# 潮汐 TIDEFLOW · 全网免费视频聚合站

一个**普通视频聚合站**：多源并行聚合（NASA 官方影像 / 开源电影 / 公版影视 / 样片库）、站内搜索、分类浏览、直链解析播放、可开关的**成人内容过滤（安全模式）**与流级广告过滤。纯静态实现，无需服务器、无需构建、无需后端。

## 快速开始

任选其一：

1. **直接打开**：双击 `index.html`（部分浏览器对 `fetch` 有 file:// 限制，推荐方式 2）
2. **本地起服务**（推荐）：
   ```bash
   cd tideflow
   python3 -m http.server 8080
   # 浏览器访问 http://localhost:8080
   ```
3. 部署到任意静态托管（GitHub Pages / Vercel / Nginx 等）即可对外访问。

## 如何添加新源

每个源 = 一个**适配器**。在 `js/sources.js` 中按以下模式添加：

```js
ADAPTERS.mySource = {
  type: 'api',                                   // 或 'static'
  async fetch(ctx) {                             // ctx: { query, category, page }
    // ... 返回 normalized item 数组
    // item: { key, id, title, desc, thumb, direct, needResolve, assetRef,
    //         source, sourceId, categories[], tags[], actors[], studio,
    //         series, date, duration, width, height, mime }
    return items;
  },
  async test() {                                 // 体检：返回 { ok, latencyMs, count, directOk, note }
    return { ok: true, latencyMs: 120, count: 10000, directOk: true, note: '正常' };
  },
};
// 然后在 SOURCES 数组登记：{ id, name, desc, candidate: false|true }
```

要点：
- `key` 全局唯一（如 `'nasa:' + nasa_id`），用于跨源去重。
- 直链能直接拿到就填 `direct`；需要按资产清单二次解析的填 `needResolve: true` + `assetRef`，播放页会调用 `resolveNasaAsset(assetRef)` 这类解析函数。
- m3u8 直链会自动启用流级广告过滤（剔除异目录分段）。

## 内容过滤说明

- **成人内容过滤**（安全模式，默认开）：对标题 / 标签 / 描述做关键词匹配（中英文），命中即不展示。关掉后仅放行被过滤内容，其余逻辑不变。
- **推广 / 广告过滤**（数据层，始终生效）：拦截赌博、博彩、抽奖、赞助等推广条目。
- **流级广告过滤**（播放页可开关）：解析 m3u8 播放列表，把不属于正片目录的分段整段剔除，避免片头 / 中插广告。

## 技术说明

- 纯原生 HTML / CSS / JS，无框架、无构建步骤、无后端。
- 视频直链由浏览器**直连源站**播放，不经过本站任何服务器；页面不注入广告。
- 源不可达时（如部分网络屏蔽 archive.org / Wikimedia），在「更新源」面板体检后自然降级或切换，不影响其余源。
