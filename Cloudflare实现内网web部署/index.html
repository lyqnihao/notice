背景与实现方案

家里有一台低功耗小主机（或 NAS），想把它当作 Web 服务器对外提供服务，但没有公网 IP，也不想在路由器上做端口映射。整体方案：

  • ClouDNS：提供永久免费的二级域名，支持 A / AAAA / CNAME / MX / NS / TXT 等记录类型（免费额度 1 个区域、50 条记录）。
  • Cloudflare：使用 Tunnel（cloudflared）打通内网，免费、无需公网 IP、自带 HTTPS 和 CDN。
  • 内网小主机：运行 cloudflared 连接器 + nginx（或任意 Web 应用）。

流量路径：浏览器 → Cloudflare 边缘节点（HTTPS）→ Tunnel → 内网 192.168.x.x:端口，全程免费。

一、ClouDNS 申请免费域名

  1. 打开 ClouDNS 官网 https://www.cloudns.net/，右上角国旗图标可切换简体中文，点击【免费注册】，用邮箱注册并到邮箱点击激活链接。
  2. 登录后，在【DNS 托管】栏目点击【创建区域】。
  1. 在弹窗中选择【免费区域】。
  2. 在免费域名窗口中，左侧输入想要的前缀（如 apple），右侧下拉选择一个可用后缀（如 .abrdns.com），点击【创建】。
如果创建时报 Creation of free domains is limited for you due to high abuse rate from your current IP network，说明当前出口 IP 滥用率过高被平台限制，更换网络环境（如手机热点）后重试即可。
  1. 点击刚创建的域名进入配置中心，在【DNS 记录】中删除默认的两条 NS 记录（原指向 cloudns.net 的名称服务器记录）。此页面先不要关闭，下一步还要回来。
ClouDNS 部分完成，免费区域永久免费、无需续期。

二、Cloudflare 添加站点

  1. 打开 Cloudflare 仪表盘 https://dash.cloudflare.com/，用邮箱注册并登录。
  2. 点击右上角【添加】→【连接域 / 添加站点】，输入刚才申请的完整域名（如 apple.abrdns.com），保持【快速扫描 DNS 记录】选中，点击【继续】。
  1. 套餐选择 Free（US$0），个人使用功能完全够用，点击【继续】。
  1. Cloudflare 会分配两个名称服务器（NS），形如 lola.ns.cloudflare.com、micah.ns.cloudflare.com，点击复制备用。
此时域名状态为"待处理 / 名称服务器无效"是正常的，下一步替换 NS 后才会变绿。

三、替换 NS 记录，完成双向托管

ClouDNS 免费域名无法在"注册商"层面修改 NS，正确做法是在 ClouDNS 的 DNS 记录里，把默认 NS 记录替换为 Cloudflare 分配的两个 NS（社区俗称"双向托管 / 伪托管"），Cloudflare 检测到解析结果后会将域名标记为 Active。

  1. 回到 ClouDNS 的域名配置中心，添加两条 NS 记录：主机（Host）填 @，值（Points to）分别填 Cloudflare 给的两个 NS 地址，并删除残留的 cloudns 默认 NS 记录。
  1. 回到 Cloudflare 点击【检查名称服务器】。通常 10～30 分钟内，域名状态变为绿色的 Active，托管正式生效；偶尔需要更久，耐心等待即可。
在状态变绿之前，先不要在 Cloudflare 的 DNS 页面手动添加 A/CNAME 记录，避免解析冲突。隧道配好后，Cloudflare 会自动创建指向隧道的 CNAME 记录。
个别后缀可能因未列入 Public Suffix List 而被 Cloudflare 提示无法添加，回 ClouDNS 换当前提供的其他后缀重新申请即可（截至 2026 年，.cloudns.org、.cloudns.biz、.abrdns.com、.cloud-ip.cc 等均可正常托管）。

四、创建 Cloudflare Tunnel

  1. 在 Cloudflare 仪表盘左侧展开【Protect & connect（保护和连接）】→【Networking（联网）】→ 点击【Tunnels】；也可以从左侧【Zero Trust】→【Networks】→【Tunnels】进入，两个入口等价。
  1. 隧道类型选择【Cloudflared】（推荐）。
  2. 给隧道命名（如 mini-computer，建议每个网络只建一条隧道），点击【保存隧道】。
  3. 进入【安装并运行连接器】页面，按小主机的环境选择安装方式：

方式 A：Windows（原文环境）

  1. 选择 Windows → 64-bit，下载页面给出的 cloudflared-windows-amd64.msi 并安装。
  2. 安装后无界面，用管理员身份打开 CMD，运行页面给出的命令（token 以页面实际显示为准）：
cloudflared.exe service install eyJhIjoiZTZiY...（你的令牌）

方式 B：Docker（Linux / 群晖 / 软路由，推荐）

docker run -d --name cloudflared --net=host \
  cloudflare/cloudflared:latest tunnel --no-autoupdate run --token eyJh...（你的令牌）

方式 C：Linux 系统服务（Debian/Ubuntu）

curl -L https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-amd64.deb -o cloudflared.deb
sudo dpkg -i cloudflared.deb
sudo cloudflared service install eyJh...（你的令牌）
令牌（token）等同于隧道钥匙，任何拿到它的人都能接入你的隧道，请勿泄露或提交到公开仓库。
连接器运行后，回到 Tunnels 列表，隧道状态显示为 HEALTHY（健康） 即连接成功。

五、配置公共主机名（映射内网服务）

隧道建好后，点击隧道名称 →【配置 / Configure】→【Public Hostname（公共主机名）】标签页 → 添加一条映射：

配置项示例说明
子域 Subdomainhost自定义，最终公网地址 = 子域.域名
域 Domainapple.abrdns.com下拉选择已托管到 Cloudflare 的域名
路径 Path留空可选，用于按路径分流
服务类型 TypeHTTP指向下游服务的协议
URL192.168.0.110:8081内网 IP + 端口（nginx 或应用监听地址）

保存后，Cloudflare 会自动在 DNS 中创建一条指向该隧道的 CNAME 记录。以后每新增一个内网服务，只需在这里再添加一条公共主机名即可，无需再动隧道本身。

六、SSL/TLS 设置与访问验证

  1. 在站点【SSL/TLS】设置中，将加密模式设为【完全（Full）】。
  2. 浏览器访问 https://host.apple.abrdns.com，即可打开内网小主机上的 Web 服务，HTTPS 证书由 Cloudflare 自动签发，无需自己申请。
至此全部完成：免费域名 + 免费隧道 + 自动 HTTPS，全程不需要公网 IP，也不需要路由器端口映射。

七、常见问题（FAQ）

1. ClouDNS 创建免费域名提示 high abuse rate？

当前出口 IP 被平台判定滥用率过高，更换网络环境（如手机热点）后重试。

2. Cloudflare 添加域名提示不支持/无效域名？

该后缀未列入 PSL，回 ClouDNS 换其他后缀重新申请。

3. 隧道显示 HEALTHY 但访问报 521 / 503？

隧道正常，问题在内网服务：检查 URL 填写的 IP:端口在内网是否可访问、协议（HTTP/HTTPS）是否选对、防火墙是否放行端口。

4. 新账号进入 Zero Trust 被要求添加付款方式？

改走账户主页【Protect & connect → Networking → Tunnels】入口创建隧道，不经过 Zero Trust 引导流程；如提示选择计划，选 Free 即可（50 用户以内免费）。

5. 想给站点加访问密码？

可以。在 Zero Trust → Access → Applications 中为该公共主机名添加 Access 策略（例如邮箱验证码登录），免费计划可用。

6. 想暴露 SSH 等非 HTTP 服务？

公共主机名的服务类型可选 TCP，外网访问端配合 cloudflared access tcp --hostname ssh.example.com --url localhost:2222 映射后使用（纯 Web 场景用不到）。
