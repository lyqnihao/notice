# 潮汐 TIDEFLOW · 全网免费视频聚合站

一个**普通视频聚合站**：多源并行聚合（NASA 官方影像 / LunaTV 采集站群 / 开源电影 / 公版影视）、站内搜索、分类浏览、直链解析播放、可开关的**内容安全过滤（安全模式）**与流级广告过滤、播放历史与收藏（可管理、可导出导入）。纯静态实现，无需服务器、无需构建、无需后端，可原样部署到任意静态托管。

## 快速开始

任选其一：

1. **本地起服务**（推荐）：
   ```bash
   cd tideflow
   python3 -m http.server 8080
   # 浏览器访问 http://localhost:8080
   ```
2. **部署到任意静态托管**：GitHub Pages / Cloudflare Pages（Drop）/ Vercel / Nginx 均可，全站相对路径 + `#q=` hash 路由，子路径部署也正常，**无需改任何代码**（详见 `DEPLOY.md`）。
3. 线上地址（lark 固定 URL）：见 `DEPLOY.md`（主站 + 镜像站）。

## 源池

源池当前以 LunaTV 采集站群为主（默认自动探测最快子站），NASA 影像库为内置源。完整列表见更新源面板（扫描体检后可勾选启用）。候选源不会自动启用。

## 如何添加新源

每个源 = 一个**适配器**。在 `js/sources.js` 中按以下模式添加：

```js
ADAPTERS.mySource = {
  type: 'api',                                   // 或 'static'
  async fetch(ctx) {                             // ctx: { query, category, page, sourceOnly, classId }
    // ... 返回 normalized item 数组
    // item: { key, id, title, desc, thumb, direct, needResolve, assetRef,
    //         source, sourceId, categories[], tags[], actors[], studio,
    //         series, date, duration, width, height, mime, episodes[] }
    return items;
  },
  async test() {                                 // 体检：返回 { ok, latencyMs, count, directOk, note }
    return { ok: true, latencyMs: 120, count: 10000, directOk: true, note: '正常' };
  },
};
// 然后在 SOURCES 数组登记：{ id, name, desc, candidate: false|true }
```

要点：
- `key` 全局唯一（如 `'luna:站点:vod_id'`），用于跨源去重。
- 直链能直接拿到就填 `direct`；需要二次解析的填 `needResolve: true` + `assetRef`。
- m3u8 直链会自动启用流级广告过滤（剔除异目录分段）。
- LunaTV 类采集站直接复用 `lunaSiteAdapter(site)`（苹果 CMS V10 协议）。

## 内容过滤说明

- **内容安全过滤**（安全模式，默认开，位于更新源面板）：对源名 / 标题 / 标签 / 描述做关键词匹配（中英文），命中即不展示；开启时源 chips、源下拉也会隐藏相关源。
- **推广 / 广告过滤**（数据层，始终生效）：拦截赌博、博彩、抽奖、赞助等推广条目。
- **流级广告过滤**（播放页可开关）：解析 m3u8 播放列表，把不属于正片目录的分段整段剔除，避免片头 / 中插广告。

## 技术说明

- 纯原生 HTML / CSS / JS，无框架、无构建步骤、无后端。
- 视频直链由浏览器**直连源站**播放，不经过本站任何服务器；页面不注入广告。
- 所有资源引用 / 页面跳转均为相对路径，搜索走 hash 路由 —— 部署到 GitHub Pages 子路径或 Cloudflare Drop 均无需改代码。
- 本地数据（启用源 / 过滤设置 / 历史 / 收藏 / 体检结果）存于浏览器 localStorage，可经更新源面板导出 / 导入备份。
