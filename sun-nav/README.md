# Sun Nav 导航页

基于 Sun-Panel 风格逆向实现的**纯静态个人网站导航页**。无后台、无数据库、无服务器监测，
数据存浏览器本地（localStorage），可直接部署于 GitHub Pages / Cloudflare Pages / 任意静态托管。

当前版本：**v1.1.3**

## 功能特性

- **深/浅色主题一键切换**，样式基于 CSS 变量，默认深色。
- **顶部搜索框**：输入即站内过滤当前页面卡片；**回车或点击"搜索"** 用搜索引擎在新标签页打开并清空输入框。
- **多搜索引擎**：搜索框下方可勾选，支持**自定义增删**（"✎ 编辑引擎"管理，搜索地址用 `{q}` 占位）；勾选多个时逐个打开搜索页、**焦点保留在本页**；页面**向下滚动时搜索选项自动收起**，点"引擎 ▾"重新展开（部分引擎页面可能被浏览器弹窗拦截，属浏览器限制）。
- **1×2 标签卡**：左侧 Logo（自动抓取 favicon，失效回退首字母），右侧站点名 + 介绍；按屏幕宽度自动多列（手机 1 列、平板 2 列、桌面 3~4 列）。
  **右键菜单**：打开外网链接 / 打开内网链接 / 上移 / 下移 / 编辑标签 / 删除标签。
- **分类与卡片均可排序**：桌面端直接拖拽；任意端（含手机）也可用右键菜单**上移/下移**。分类支持右键重命名、添加站点、删除。
- **左侧可折叠分类树**：点击切换分类、显示"全部站点"，固定分类带"固定"标记，窄屏自动收纳。
- **增删改**：页面按钮即可完成（+分类、+添加站点、编辑、删除），数据自动保存到浏览器；
  **导出可选格式**（Sun-Panel JSON / 浏览器 HTML 书签），**导入自动识别**本应用 JSON、Sun-Panel 备份、Chrome/Edge/Firefox 书签 HTML 三种来源，另提供**重置**。
- **顶部固定功能卡**（"功能工具"分类，不可随数据丢失）：
  - **IP 与连通性测试**：自包含实现（参考 ip.skk.moe），实时显示公网 IP/归属地/ISP，
    并对百度/Google/GitHub/OpenAI/Cloudflare/YouTube 等主要站点做连通性探测（显示延迟），每 30 秒自动刷新。
  - **日历与时钟**：实时时钟 + 当月日历（高亮今天与周末）。
  - **网络检测 / IP 信息检测** 网站导航若干（IPCheck、ip.skk.moe、ip111、IPv6 测试、ipleak、itdog 等）。

## 性能优化（条目多不卡顿）

- 卡片图片 `loading="lazy"` 懒加载 + `referrerPolicy` 防泄漏。
- 全部视图下分类区块使用 CSS `content-visibility: auto` 懒渲染。
- Logo 加载失败自动回退为站点首字母，不阻塞布局。
- 数据渲染基于原生 JS 轻量实现，无第三方框架依赖。

## 目录结构

```
sun-nav/
├─ index.html           入口页
├─ css/style.css        样式（深/浅主题变量）
├─ js/app.js            逻辑（状态、渲染、搜索、右键菜单、拖拽、widget）
├─ js/data.js           站点数据（完整版，含本地/自建使用）
└─ deploy-public/       公开部署版（已剔除敏感分类，仅用于发布公网）
```

## 本地运行

直接双击 `index.html` 用浏览器打开即可（数据在本地 localStorage）。
或任意静态服务器托管该目录：`python3 -m http.server 8080` 后访问 `http://localhost:8080`。

> 注：file:// 方式打开时，IP 检测接口受浏览器 CORS 限制可能显示"获取失败"，
> 部署到 http(s) 后即可正常获取 IP。

## 数据说明

- 默认站点数据来自 `js/data.js`（`window.SUN_PANEL_DATA`）。
- 页面内增删改会写入浏览器 localStorage 并优先于默认数据加载。
- 完整版 `js/data.js` 含全部分类；`deploy-public/js/data.js` 为公开部署版，
  已剔除敏感分类（Pornhub / 搭梯子 / 公益机场），避免公网链接与平台内容政策冲突。
- 日后新增站点：可在页面点"添加站点"，或直接告知维护方在 `js/data.js` 对应分类中追加后发新版本。
