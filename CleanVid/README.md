# 清影 CleanVid —— 普通影视聚合站

纯前端静态站，聚合多个公开 MacCMS 风格资源接口，**严格过滤成人/色情内容**。

## 功能

- 多源并行聚合（默认 3 条高速源，可扩展源池）
- 首页最新上架 + 电影 / 电视剧 / 动漫 / 综艺分类
- 跨源搜索，结果去重合并
- 头部「更新源」：扫描源池可用性、测速、勾选应用；可在线搜新源加入池
- 卡片标题最多 3 行，悬停可滚动完整标题；一行演员/标签（可点搜索）
- 播放页：HLS.js 直连 m3u8、广告分段过滤开关、右侧直链复制、完整资料（厂商/系列/演员/导演/年份/地区/标签等，全部可点进站内搜索）
- 移动端沉浸式播放，无横向溢出
- 本地收藏（localStorage）

## 使用方式

1. 直接用任意静态服务器打开 `index.html`（推荐 Live Server / nginx / Cloudflare Pages / Vercel 静态）
2. **跨域说明**：多数资源站未开 CORS。本地或线上请任选其一：
   - 使用浏览器扩展临时放行（仅自测）
   - 部署简单反代（见下方 `proxy-example`）
   - 把 `js/config.js` 里的 `CORS_PROXY` 改成你自己的中转地址
3. 源列表在 `js/config.js` 的 `SOURCE_POOL` 中维护，可自行增删

## 目录结构

```
clean-video-site/
├── index.html          # 主页 + 播放页单页应用
├── css/style.css
├── js/
│   ├── config.js       # 源池、过滤规则、CORS 代理
│   ├── api.js          # 请求、去重、成人过滤
│   ├── player.js       # HLS 播放 + 广告段剔除
│   └── app.js          # UI 与路由
├── assets/
└── README.md
```

## 成人内容过滤策略

- 分类名命中：伦理、情色、成人、AV、色情、三级、限制级 等
- 标题/标签命中敏感词库
- 可在 `config.js` 的 `ADULT_KEYWORDS` / `ADULT_TYPE_KEYWORDS` 自行加强
